# 上财 WebVPN 实测记录

这个文档记录上海财经大学 WebVPN 的实际使用情况，都是踩过坑之后写下来的。如果你也遇到类似问题，可以对照着处理。

## 已知问题

### 1. 知网包装地址报「IP 不在许可范围」

- **现象**：从数据库导航点知网，地址变成 `https://www-cnki-net-s.webvpn.sufe.edu.cn/`，页面能打开，但点「机构登录」时提示 IP 不在许可范围内，或者 IP 登录一直卡在「登录中」。
- **原因**：知网的机构认证靠 IP 识别。WebVPN 改写的地址在知网侧没有正确对上学校的 IP 段，导致机构访问失效。
- **处理**：不走 WebVPN 访问知网。直接在专用 Chrome 里打开 `https://www.cnki.net/`，用个人账号登录。个人账号的下载权限不依赖学校 IP。

### 2. 知网滑块验证码反复出现

- **现象**：走 WebVPN 打开知网首页，经常弹「拖动下方拼图完成验证」。
- **处理**：验证码属于安全验证，脚本不会碰，自己拖一下就好。但如果反复弹，多半是触发了反爬，歇一会儿再操作，不要连续快速检索。

### 3. 数据库导航页加载不全

- **现象**：`https://sufe-libguides-com-s.webvpn.sufe.edu.cn/az.php` 偶尔只显示部分链接，点不到目标数据库。
- **原因**：页面是动态渲染的，网络慢时可能只加载了一部分。
- **处理**：等几秒让它继续加载，或者刷新一次页面。脚本里已经加了等待重试逻辑。

### 4. WebVPN 登录态会过期

- **现象**：用着用着访问数据库时被弹回 `https://login-sufe-edu-cn-s.webvpn.sufe.edu.cn/login/`。
- **处理**：重新登录一次就好。专用 Chrome 的 profile 会尽量保留会话，但学校这边过期了就得重来。

## 哪些库走 WebVPN 是好的

实测没问题的：

- **ScienceDirect**：`https://www-sciencedirect-com-s.webvpn.sufe.edu.cn/`，机构访问正常，检索下载顺畅
- **Springer Link**、**Oxford Academic**：同类的包装地址，正常
- **CSMAR / Wind / WRDS** 等数据平台：从数据库导航进入正常

## 通用提醒

1. 通过 WebVPN 访问时，你的流量会走学校出口 IP，**短时间大量检索容易被出版商判定异常**，控制节奏。
2. 下载的论文只用于个人学习研究，别批量爬、别传播。
3. 学校账号被拉黑名单是大事，宁慢勿快。
